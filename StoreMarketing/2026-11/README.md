# Store marketing source — November 2026

The tracked Python scripts and `listing-copy.json` preserve the screenshot, video and listing-copy work. Generated store graphics/videos, signing/export files, submission-state evidence and account screenshots remain local and are excluded from Git.

The scripts use app screenshots and screen recordings from the local validation directories, including the separate Swedish app project. Those source recordings are not required to build the Finnish native apps. See the source paths in each script before regenerating promotional material.

Historical submission notes in the copy file describe the state when it was prepared; they do not establish the current App Store or Google Play release status.
